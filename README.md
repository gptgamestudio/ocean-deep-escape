## 🎮 Game Features
* **500 Abyssal Zones:** Deep ocean progression with escalating hydrothermal hazards and apex predators.
* **Apex Boss AI:** Must defeat the colossal **Leviathan Prime** to unlock the deep escape portal to the next zone.
* **Unlimited Sonar Torpedoes:** Zero ammo exhaustion with rapid-fire sonar harpoons.
* **Pure Submarine Survival:** Real countdown death removed for continuous tactical exploration.
* **Zero-Latency Procedural Audio:** Synthesized sonar pings, thruster cavitation rumble, and victorious fanfare.
* **Global Realtime Sync:** Pilot callsign and records sync automatically to Firebase.
